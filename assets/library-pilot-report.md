## 看到的两个失败模式（截图 evidence/library-pilot-sheet.png）

1. **被误收**：`pighub-1324 幽幽猪` 是一只**绿色**的猪，palette 却给了 0.772 —— 说明「桃色/玫红」色带判据对异色猪不可靠，per-palette 打分不能当唯一闸门。
2. **被误留**：`pighub-1322 以撒猪` 实际保留了**整张白色卡片**（卡片描边是一个大连通块，按「像猪度×面积」被选中），里面的两只小猪反而成了配角。

## 结论

**自动精修达不到发布标准。** 40 张里就有两类硬伤，扩大到 1361 张只会更多。
所以全库精修不采用「一键批处理」，而是把这条管线降级为**分流工具**：

- 它负责：下载、去白、候选连通块排序、风格初筛、生成缩略图与分数；
- 它不负责：定稿。定稿仍然是一张一图：subagent 看图 + 逐像素测量 → spec → 复算核对 → 人审。

这与用户此前的要求一致（「分派 subAgent 逐素材专项处理，禁止批处理一刀切」）。
