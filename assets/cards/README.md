## 结论（必须如实说）

批处理能**出样**，但达不到「角色卡」成品标准。目检 25 张里 11 张不合格，失败集中在三类：

1. **底卡没去掉**（方块/三角/圆形色块被当成猪身）：色块与猪身同为桃色，纯像素判据分不开「卡片」与「猪」；
2. **直角切边**：源图本身把猪裁在画布边，成品四边是平的；
3. **图上仍有台词文字**：文字与猪身粘连，去背景去不掉。

这三类都只能**逐素材判定 + 手工框选**（即 subagent 流程），不能靠批处理。
