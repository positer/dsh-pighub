## 结论

批处理能出样，但达不到「角色卡」成品标准：已目检的 24 张里 9 张不合格。

失败模式与**可量化的判据**：

| 模式 | 判据 | 处理 |
|---|---|---|
| 矩形底卡 | 连通块 bbox 填充率 ≥ 0.92 且面积 > 25% | **生成时自动排除**（本轮排掉 8 张） |
| 三角/圆形底卡 | 填充率 0.5~0.8，逃过阈值 | 只能逐图判定 |
| 直角切边 | 连通块 bbox 贴画布边（flatEdges ≥ 1） | 源图限制，只能选择接受或弃用 |
| 角色名残留 | 文字与猪身粘连，去背景去不掉 | 只能逐图框选 erase |

要 50 张全部达标，必须走逐素材 subagent（框选底卡边界、框掉台词、判定切边去留）——这正是 objective 第 2 条要求的流程。
