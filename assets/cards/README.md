## 口径

- **是角色**：单只猪形象（可以带一体化的造型，如西瓜猪、狮子猪、摩羯猪）；行为梗、场景截图、多主体、以人形为主体的不算。
- **名字去净**：图上不得残留角色名/台词/品牌字；气泡、屏幕、卷轴里的文字同样算残留。
- **可爱闸门**：血腥、獠牙撕咬、伤口、武器、猎奇造型（人形肌肉、血盆大口、油炸化）一律不进包，理由逐条写在这里。
- 判据只看像素与标题无关：叫「怪猪」的照收，叫「可爱猪」的照样要过闸门。
