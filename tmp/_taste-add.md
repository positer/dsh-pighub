## Z. 用**一张位图**做分层围栏（2026-11-14「木栅栏 + 景深 + 红框草坪」那一轮固化）

> 只在末尾追加。本节回答「用户给了一张方框围栏图，要它当猪圈、还要有前后景深，怎么做才不毁图」。
> 编号用 Z：A–Y 已被占用（且 H/I/M/P/Q 有重号，见 §P 开头说明）。

1. **先量图，再动手；任务书里的「白底」可能不成立**。本轮原图的背景其实是 `alpha=0`（四角 `(0,0,0)`/alpha 0），
   「边缘近白」规则跑完命中 **0** 像素。判据：把规则跑一遍、把读数写进报告——**收获为 0 也是读数**，
   不许因为「看起来该有白底」就伪造一次删除。同理，用户画的标注（红框）可能只存在于**后发的另一份文件**里，
   量坐标要去那一份量，产品里用干净的那一份。
2. **「切两层」不等于「两套像素」**。同一条水平线、每行只归一层，叠回去才可能逐像素相等（本轮 0 差异）。
   允许的模糊只有一种：`alpha=0` 像素的直通 RGB 是 unpremultiply 的定义域噪声（本轮 2262 px，最大 7/255），
   判据必须写在**显示空间（预乘）**上，并把这条噪声单独记一笔——不要把它算成「切分误差」。
3. **接缝是这种做法的全部风险，且它不在图像里、在渲染里**。同一张图同一个位置画两遍，只要边界是
   `clip-path` / 预切半透明图 / `background-size` 缩放比不一致，接缝就会亮（本轮实测 +14/+18/整体糊）。
   能过的是**溢出裁剪（`overflow:hidden`）+ 两个同样的「方块 shot」，一个贴顶、一个贴底**：
   Skia 的硬裁剪按整像素归属，每行只归一层。判据 = 「两层 vs 单层」逐像素差 0（本轮 452×452 实测 0）。
4. **先做对照，再报「通过」**。把同一张图渲染两次的差（本轮 167 px / ≤4/255）当**噪声地板**报出来，
   再拿方案跟它比——否则那点零头会被当成方案缺陷，或者反过来被当成「0 差异」蒙过去。
5. **z 序要写成「顺序 + 档位」，不要写死四个数字**。本轮猪那一档是 `Z_ACTOR_MIN..MAX`（按脚底名次排，
   另一条线做的），围栏是单值。测试守的是 `back < house < Z_ACTOR_MIN ≤ Z_ACTOR_MAX < front < settings < gallery`，
   常量从 `__test` 取——这样别人再改档位，红的是「顺序错了」，不是「数字变了」。
6. **草坪只能铺在给定区域，且区域必须由**一个**常量表达**。本轮 `PEN_GRASS`（红框外沿）、`PEN_INNER`（栅栏内圈）、
   `PEN_BOX`（圆心活动区 = 内圈各收半个猪身）三个矩形，包含关系写成断言
   （`PEN_GRASS ⊃ PEN_INNER ⊃ PEN_BOX ± 半个猪身`）。红框取外沿而不是内沿的理由要给数：
   远栏底面 18.7%、红线内沿 20.02% —— 取内沿会在栏下留一条没有草的亮带。
7. **「猪圈自己不画像素」要能被测，而不是「我记得改了」**。`.pighub-pen{background:transparent}` + 无描边 +
   无铺满全圈的叠层，写成 CSS 断言；再加上「围栏外 6 个采样点 == 插件不在时同坐标」的真机读数
   （本轮两边都是 `[21,21,23]`）。**「看起来不绿」不算证据。**
8. **家具压住背景要量重叠，不要目测**。小屋「挡住后栏」的判据是：小屋开/关两帧差分 ∩ 原图不透明像素 = 2079 px，
   其中上横梁 693 px、下横梁 1016 px，被遮竖直高度 53 px；并且被遮的像素**全部在分割线以上**（否则前景栏被盖）。
9. **并排对照图里要把「缩放器差异」和「内容差异」分开**。左=原图缩到 452、中=渲染、右=差异 ×4 时，
   围栏不透明像素的 `均值 3.2/255、>8/255 占 4.4%` 是两个缩放器（PIL LANCZOS vs Skia）在抗锯齿边上的差；
   围栏本身的差要用「两层 vs 单层」那一栏（0）说话。两个数都给，别混成一句「看着一样」。
10. **临时探针用 `_` 前缀、构建期脚本不用**。本轮 `scripts/pen-fence-split.py`（管线，可重跑、自带断言）
    与 `scripts/_pen-fence-probe.py`（一次性量数）分开，前者进包，后者只留档。
